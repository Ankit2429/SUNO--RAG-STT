# SUNO Five-Color Reference

The supplied wide reference contains five rounded swatches in left-to-right order: a muted brick red, warm textured cream, saffron orange, deep forest green, and cobalt blue. Each swatch is framed by a dark blue outline; the source does not provide exact hexadecimal values.

SUNO will use this order as a semantic system: cream for the primary canvas, dark text/structure derived from the deep blue outline, red for refusal and recovery emphasis, saffron for voice and active actions, forest green for grounded evidence, and cobalt for routing and navigation cues. The implementation will keep contrast-led text treatment and will not alter the voice-RAG pipeline.
